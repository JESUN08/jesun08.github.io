## Features

- 🎨 Dark neon design with 3 themes (Default, Dark, Light)
- 📊 Real shared stats via Supabase that update live for everyone: visitors, visitors today, likes, hearts, email clicks, link clicks, most clicked link
- ☰ Slide-over menu: each section (Edits, Code & Projects, Goals, Connect, Contact) opens as its own view
- 🎯 Goals tracker with progress bars, updated live from Supabase
- 🟢 Live visitor count using Supabase Realtime Presence
- 👍 ❤️ Like and heart reactions (one each per device)
- 📧 Tap an email to open your mail app and write to me, or copy it with one tap
- 🔗 One-tap website link copy
- 🎂 Live birthday countdown
- 📱 PWA, installable on phone and PC as an app
- ⚡ Smooth animations and scroll effects
